# Identity & Access Management API

Backend desarrollado con Spring Boot siguiendo arquitectura hexagonal.

## Tecnologías

- Java 21
- Spring Boot 3
- Spring Security
- JWT
- PostgreSQL
- Flyway
- MapStruct
- Docker
- JUnit 5
- Maven

## Objetivo

Construir una API de gestión de identidades y accesos inspirada en sistemas empresariales reales.

Características previstas:

- Registro y autenticación de usuarios
- Gestión de roles y permisos
- JWT Authentication
- Auditoría
- Rate Limiting
- Arquitectura Hexagonal
- Tests unitarios y de integración
- Dockerización
